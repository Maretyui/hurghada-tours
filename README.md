# Hurghada Tours

Landing page for a Hurghada-based tour operator — luxury day and multi-day excursions to Luxor, Cairo, and other iconic Egyptian destinations, with drivers speaking English, German & Arabic.

**Status:** sample/placeholder content, not yet approved for production use (see on-page disclaimer).

## Stack

- Static HTML, CSS, and JavaScript — no build step or framework

## Structure

- `index.html` — disclaimer/entry page
- `home.html` — main landing page (hero, tours, vehicles, about, contact)
- `impressum.html` — legal notice
- `credits.html` — credits
- `style.css`, `script.js` — shared styles and behavior
- `images/` — page assets
